API → Snowflake Data Flow & CX Dashboard

Pulling customer data for the CX team's reports was a manual job that took 3+ hours. case_05 · market intelligence
guessing 502 jobs
39 tools · remote data & AI roles

Remote Data & AI Job Market Dashboard

I scraped 502 public remote job postings with Firecrawl and parsed them with a deterministic Python pipeline (an LLM extraction hallucinated salaries, so I replaced it). The result is a star schema (jobs, tools, bridge) that feeds an interactive React dashboard: which tools employers ask for, how demand splits by role family, and AI mentions. Salary is disclosed in only 38% of postings, and the dashboard says so. I also packaged the same view as a custom Power BI visual with cross-filtering.

Python Firecrawl React Power BI custom visual Star schema
→ Live dashboard → Code & pipeline
